# Quête du Quotidien a déménagé

L'application est maintenant à l'adresse **https://quete-du-quotidien.web.app**.

Sur iPhone : supprime l'ancienne icône de l'écran d'accueil, ouvre la nouvelle adresse dans Safari, puis
Partager → « Sur l'écran d'accueil ».

Ce dépôt ne sert plus qu'à rediriger les anciennes installations.
